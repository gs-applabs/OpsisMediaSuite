# Experimental LibVLC native playback host
Separate WinForms window, local files only, process isolation (not a security sandbox). Explicit user action only; not an automatic fallback or embedded adapter. Own transport, audio/subtitle tracks, external subtitles, delay and volume. Source uses pinned LibVLCSharp 3.10.2 / VideoLAN.LibVLC.Windows 3.0.24 (non-GPL package); .NET 10 Windows x64. No global codec settings changed. CI compiles and runs a real generated MKV with two audio tracks and SRT, using dummy video/audio outputs. This verifies playback clock and track selection, not rendered pixels, audio quality or GPU. Source-only until CI and redistribution/license review. For development run dotnet publish native-player/Opsis.NativePlayer.csproj -c Release -r win-x64 --self-contained true -o native-player/publish. Main process discovers that exact executable in dev, or resources/native-player/Opsis.NativePlayer.exe in packaged build; no native binary auto-download. Do not copy unverified binaries into this location. Native host does not share Chromium DSP or resume yet. DirectShow/Media Foundation adapters pending. VideoLAN licensing review and notices required before distributing native artifacts.
