# OpsisMediaSuite — FAQ / Συχνές ερωτήσεις

**Focus / Αντικείμενο:** Media playback and enhancement / Πολυμέσα και επεξεργασία ήχου

## Where do I download it? / Πού το κατεβάζω;

[Latest stable published release](https://github.com/gs-applabs/OpsisMediaSuite/releases/latest). Select the official installer and matching SHA-256 file if provided. Read the requirements, limitations and upgrade notes. A hash is an integrity check, not a signature or proof of safety. Do not bypass OS warnings.

## How do I get started? / Πώς ξεκινάω;

Check the media format and the release notes before reporting playback or conversion problems.

## What are the limitations? / Ποιοι είναι οι περιορισμοί;

Format support depends on the player and codecs. The plugin bridge launches the installed application; it is not a complete now-playing bridge. / Η υποστήριξη μορφών εξαρτάται από player και codecs. Το plugin εκκινεί την εφαρμογή.

## Where do I find screenshots? / Πού βρίσκω εικόνες;

[Actual Windows CI screenshot gallery](product-snapshots/README.md). Some views use demonstration data. Visual tests are not full functional acceptance tests.

## Can I report a bug or suggest a feature? / Μπορώ να αναφέρω σφάλμα ή να προτείνω δυνατότητα;

[Open an issue](https://github.com/gs-applabs/OpsisMediaSuite/issues/new/choose). Include your app and Windows versions and steps to reproduce. Redact personal data, credentials and confidential files.

## What is planned? / Τι σχεδιάζεται;

Demonstrations using rights-cleared sample media; expanded playback and converter tests.

This is a non-binding direction, not a promised release date. / Ενδεικτική κατεύθυνση, χωρίς δεσμευτική ημερομηνία.
